How to get a free API key (2 minutes) + keep it safe
  1. Go to console.cloud.google.com and create a project (or pick one).
  2. Open APIs & Services → Library, search “YouTube Data API v3”, click Enable.
  3. Open APIs & Services → Credentials → Create credentials → API key. Copy it.
  4. Restrict the key (important): click it, under API restrictions choose “Restrict key” → YouTube Data API v3. Under Application restrictions → HTTP referrers, add bookofjam.com/* and *.bookofjam.com/* (and localhost/* for testing). Save.
  5. Paste the key above and hit Load.

The key lives only in your browser (localStorage) — it is never committed to the repo or sent anywhere except Google's API. The referrer restriction means that even if someone saw it, they couldn't use it off your domain. The Data API gives read-only public stats; it cannot change anything on your channel.

Want day-by-day history, watch time, retention and traffic sources? That needs the YouTube Analytics API with OAuth sign-in — ask and it can be added as a next step. Until then, this page builds its own growth history by saving a snapshot each time you open it.
